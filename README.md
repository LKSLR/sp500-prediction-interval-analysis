## sp500-prediction-interval-analysis
OLS regression 2015-2021 and prediction interval analysis for 2023 of the iShares Core S&amp;P500 ETF using Python.



# Objectives

#The purpose of this project is to explore how statistical methods can be used to estimate future market #developments while also demonstrating their limitations.

# Method

By applying an Ordinary Least Squares (OLS) regression model to historical ETF price data, we obtain a strong fit for the observed market trend between 2015 and 2021. Based on this trend, the model is then used to generate an out-of-sample forecast for 2023.

# Findings

Although the regression line appears to describe the historical data accurately, the prediction interval reveals substantial uncertainty caused by market volatility. This demonstrates an important limitation of simple linear models in financial forecasting.

# Conclusion

The project therefore serves not only as a forecasting exercise, but also as an introduction to risk, uncertainty, and the challenges of modeling financial markets.

Future projects will explore more advanced methods such as multiple regression models and the inclusion of macroeconomic and geopolitical factors.
